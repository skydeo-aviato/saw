# Cycle

Ours — but the contract is not this body: the ritual and its draft content contract live in the
commitment charter, `commitment.md` beside this file. **Read the charter first and
draft to its contract exactly** — this file carries only what a Claude Code session does around
it, so the ritual's definition stays in one place. The Claude Tag routine drafts the same
contract from the alarm; this command is the ritual's second surface, so the boundary never
depends on the alarm being up.

**Read Linear only; write nothing to shared records.** No issue field, no `cycleId`, no comment,
no Linear document. The human moves the issues — selection *is* the drag into the cycle — and
the human posts the note.

## 1. Find the boundary

Read the Platform team's cycles. The closing cycle is the active one; the boundary is its
`endsAt`; the next cycle is the one the human will fill.

**No active Platform cycle → say so and stop.** The ritual has no boundary to draft against.

## 2. Gather what the contract consumes

Read everything before drafting anything:

- the closing cycle's issues — state, assignee, and how each entered: selected at the boundary,
  or added after the cycle started (the issue's history says which — that is a break-in)
- open issues eligible under the Priority model, `../../references/linear.md` §4
- Linear's 3-cycle velocity figure, and the closing cycle's actual

Where Linear does not say why an issue missed or what a break-in displaced, leave the slot
marked for the human — an empty reason beats an invented one.

**Done when every fact the contract's four sections need is read, or marked unknown.**

## 3. Draft the artifact

One reviewable document, delivered in the session — the contract's four sections, in ritual
order, its bounds applied as written. The goal line stays blank and the pool carries no
selection: step 4 (selection + cycle goal + owners) is the human's alone, so present it as their
act between reading the draft and signing the note — never as a section you fill.

**Done when the human can perform the whole ritual from the draft alone** — every veto, the
selection, and the note need only their judgement, not more reading.
